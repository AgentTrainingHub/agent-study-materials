## 获取全部源码

```bash
git clone https://github.com/AgentTrainingHub/agent-study-materials.git agent-study
cd agent-study
```

源码路径与实验书中的 `course/week-XX/practices/PRA-WXX/` 一致。各实验的 Python 版本、依赖安装和运行顺序以对应实验书及目录内的依赖文件为准。真实模型调用需要自行配置环境变量中的 API Key，并会产生模型服务费用。
