# 端口解析代码检查

先实际读取当前代码，再对照本轮用户条件检查接受的字符与数值范围。保留函数接口和用户明确要求保留的行为。

提出修改前，读取 references/checklist.md 并逐项选择相关检查。清单包含容易遗漏的输入与测试要求，目录描述无法代替它。

修改需要使用宿主 edit/write 工具并等待批准。完成后调用固定 shell check，依据其实际返回说明检查情况；仅看到代码或测试文件不能称检查通过。

最终说明实际修改、验证结果和仍未知的部分，引用实际读取的行号。
