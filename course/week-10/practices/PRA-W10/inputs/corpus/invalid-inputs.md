# 非法输入对照表

适用条件：本表仅用于 semicolon_keep；左列均为传给 parse_ports 的实际 Python 值，所有行都应抛 ValueError，不返回部分结果。

| 输入值 | 拒绝原因与适用限制 |
| --- | --- |
| `""` | 空字符串没有端口项；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `None` | 非字符串值没有列表语义；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `80` | 整数不能替代字符串输入；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `True` | 布尔值不能替代字符串输入；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;;443"` | 相邻分号造成中间空项；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `";80"` | 开头分号造成首项为空；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;"` | 结尾分号造成末项为空；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80,443"` | 逗号不能作为本合同分隔符；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80; 443"` | 第二项含有前导空白；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;１２"` | 全角数字不属于 ASCII 数字；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;٠٨"` | 阿拉伯数字不属于 ASCII 数字；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;080"` | 第二项含有前导零；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;0"` | 第二项小于闭区间下界；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
| `"80;65536"` | 第二项超过闭区间上界；整个列表必须同时满足非空字符串、分号分隔、逐项 ASCII 无前导零以及闭区间要求，任一项非法时整次拒绝。 |
